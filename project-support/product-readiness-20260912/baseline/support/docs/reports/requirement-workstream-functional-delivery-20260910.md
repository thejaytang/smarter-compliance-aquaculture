## Known limits and manual cases

Manual original checks remain necessary for uncalibrated or conflicting evidence, OCR errors, numbers/negation, difficult tables, captions, footnotes, reading order and complete cross-page parent boundaries. The manual fallback requires comparing the actual original, recording the exact correction and then completing both gates. It does not automatically rewrite an already transcribed parent after a linked-cell correction; the dependency instead reopens that parent for comparison and correction.

Formal precision/recall, verifier false-positive/false-negative rates, independent association/subdivision accuracy and confidence calibration have **not** been accepted. All 13 historical Gold samples remain exposed development/regression material. Synthetic omissions/judgment errors are explicitly distinguished from natural failures. Broader real scanned/mixed/language/template suitability and automatic processing share remain future work.

Earlier isolated B history lacked explicit classification fields. Those entries remain unchanged and labelled, and no missing decision is inferred from notes or later state. The normal database had no B decision history before the correction; new decisions retain exact before/after classifications and source/time identity.

Native Excel inspection of the latest long-note/context-height changes remains outstanding because the Mac is locked. Original content is present in the database, browser and complete cell values; the workbook explicitly supports full-cell/formula-bar reading. Earlier native workbook/core-source inspection is reused only for the artifacts actually inspected. Latest Office validation/readback is not called native visual acceptance. This remaining display check does not block the demonstrated workflow.
