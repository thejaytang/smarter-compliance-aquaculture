- Figure visual understanding 和 equation LaTeX 是 `derived`，不能覆盖原始 crop、bbox 或相邻文本证据。
- 外部托管 OCR/VLM 默认关闭；当前最终验收没有向外部服务发送文档内容。
- 跨文档引用在目标文档不存在时只保存 candidate，不伪造 target。
- 通用公开 benchmark 已从当前验收体系移除；后续质量判断以法律法规、通用办法和标准类 PDF 的内部 Gold Set 与真实生产文档回归为准。
- 本项目目录不是 Git repository，因此 `pipeline_commit` 使用源码树 SHA-256，而不是伪造 Git commit。

## 2026-08-26 真实生产 PDF 层级与页眉页脚回归

输入 `data/inputs/ASC-INT-001-ASC-Farm-Standard-Interpretation-Manual-V1.0-May-2025.pdf` 的第 7–9 页曾作为真实回归样本。

- 跨页 native marginal template 预识别已接入逐页解析之前，支持全局、奇偶页及连续局部重复。
- 同页页眉/页脚碎片合并为单一 block，Markdown 不再包含页脚元数据。
- native glyph geometry 可恢复 Layout/OCR 遗漏的 `o / • / -`，并按 x-position cluster 生成 0/1/2 级列表层级及父子关系。
- list continuation paragraph 会并入所属项目，同级带符号项目不会误合并。
- numbered heading 为标题层级提供锚点，续页顶部普通小标题不再误判为 level 1。
- paragraph merge 的 conflict references 会迁移到保留 block；completeness gate 不再把空格 character 当成遗漏。

最终结果：`accepted`、review queue `0`、validation errors `[]`、三页 unassigned native objects 均为 `0`、automatic coverage `1.0`、provenance anchor coverage `1.0`。完整测试为 `61 passed, 1 skipped`。
