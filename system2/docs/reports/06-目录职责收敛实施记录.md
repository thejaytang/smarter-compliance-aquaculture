# 目录职责收敛实施记录

## 2026-09-01

决策：`CONTINUE`。

## Root cause

此前 `domains/` 和 `delivery/` 只是公共 facade，实际业务实现仍与 facade 并列在
`requirements/`、`regulatory_ir/`、`export/`、`ontology/` 和根 `derived.py`。
因此目录名称表达的架构与代码真正归属不一致。测试同时全部堆在根目录，并以
`Path(__file__).parents[1]` 隐式依赖所在层级。

## 已实施

- Requirement 实现迁入 `domains/requirements/`。
- Regulatory IR 实现迁入 `domains/regulatory/`。
- Markdown、HTML、XML、JSONL、RAG 和 overlay 实现迁入
  `delivery/exporters/`。
- RDF/SHACL 实现迁入 `delivery/ontology/`。
- derived artifact writer 迁入 `delivery/writer.py`。
- 旧 `requirements/`、`regulatory_ir/`、`export/`、`ontology/` 和 `derived.py`
  保留 thin compatibility facade；新旧入口返回相同对象。
- 测试迁入 `contracts/`、`unit/`、`integration/` 和
  `domains/requirements/`；共享根路径迁入 `tests/support/paths.py`。
- 新增 namespace layout contract，禁止旧目录重新产生第二套实现。
- 清理可再生成的 `__pycache__`、`.pytest_cache` 和 `.DS_Store`。
